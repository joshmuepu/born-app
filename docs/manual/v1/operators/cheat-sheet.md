# Service Day cheat sheet

A quick reference for someone who already knows BORN but wants a refresher before
the room fills up. For the full walkthrough, see [Quick start](quick-start.md).

## Before anyone arrives

1. Turn on the Congregation screen (and Stage monitor, if used) **before** opening
   BORN.
2. Open BORN. Confirm the footer (bottom-left) shows a sermon count, not "Starting…"
   or a damaged-data warning — see
   [Backups and a damaged database](../troubleshooting/data-recovery.md) if it does.
3. Build the queue: search or browse Sermons/Bible/Songs, **+ Queue** everything in
   order.
4. Click **Open projection** and confirm the Congregation screen shows it, not the
   operator's own laptop screen — see
   [Connecting a second screen](../setup/displays.md) if it picked the wrong one.

## During the service

- **Next** / **Back**, or <kbd>Space</kbd> / <kbd>Shift</kbd>+<kbd>Space</kbd> —
  move through the current item.
- <kbd>Esc</kbd> or **Hide screen** — blank the screen instantly for prayer or a
  baptism.
- **Message** — a short note across the bottom of the screen, without losing
  what's currently projected.
- If a second operator is running the remote from a phone: confirm it still says
  **Connected** at the top.

## If something looks wrong

- Screen shows nothing: check **Hide screen** isn't on (it turns amber and says
  **Show screen** when it is), and that **Open projection** says **Close
  projection** (meaning it's already open).
- Wrong screen has the words: see
  [Connecting a second screen](../setup/displays.md).
- A phone stopped responding: see
  [If a phone can't connect](mobile-remote.md#if-a-phone-cant-connect).
