# Keyboard shortcuts

The same list is always one key away in the app itself: press <kbd>?</kbd>
anywhere in the main window.

| Keys | What it does |
|---|---|
| <kbd>→</kbd> or <kbd>Space</kbd> | **Next** — next slide, then rolls into the next verse/paragraph |
| <kbd>←</kbd> or <kbd>Shift</kbd>+<kbd>Space</kbd> | **Back** — previous slide/verse/paragraph |
| <kbd>⌘/Ctrl</kbd>+<kbd>→</kbd> / <kbd>←</kbd> | Next / previous **item** in the service queue |
| <kbd>Esc</kbd> or <kbd>B</kbd> | Hide / show the congregation screen |
| <kbd>⌘/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | Open / close the projection window |
| <kbd>/</kbd> | Jump straight to the search box, from anywhere |
| <kbd>⌘/Ctrl</kbd>+<kbd>Enter</kbd> | Project the top search result |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Move the on-screen item up / down the queue |
| <kbd>?</kbd> | Show / hide this list |
| <kbd>F1</kbd> | Open / close this manual |

<kbd>/</kbd> only jumps to the search box when you're not already typing somewhere
else (it won't interrupt you mid-sentence in the Message dialog, for example).
