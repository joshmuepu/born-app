# Keyboard shortcuts

The same list is always one key away in the app itself: press <kbd>?</kbd>
in the main window (when you are not typing in a box).

| Keys | What it does |
|---|---|
| <kbd>→</kbd>, <kbd>Space</kbd> or <kbd>Page Down</kbd> | **Next** — next slide, then rolls into the next verse/paragraph |
| <kbd>←</kbd>, <kbd>Shift</kbd>+<kbd>Space</kbd> or <kbd>Page Up</kbd> | **Back** — previous slide/verse/paragraph |
| <kbd>⌘/Ctrl</kbd>+<kbd>→</kbd> / <kbd>←</kbd> | Next / previous **item** in the service queue |
| <kbd>Esc</kbd> or <kbd>B</kbd> | Hide / show the congregation screen. If a window or menu is open, <kbd>Esc</kbd> closes it first |
| <kbd>Shift</kbd>+<kbd>Esc</kbd> | Hide / show the congregation screen, even with a window or menu open |
| <kbd>⌘/Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | Open / close the projection window |
| <kbd>/</kbd> or <kbd>⌘/Ctrl</kbd>+<kbd>F</kbd> | Jump straight to the search box, from anywhere |
| <kbd>⌘/Ctrl</kbd>+<kbd>Enter</kbd> | Project the top search result |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> | Move the on-screen item up / down the queue |
| <kbd>?</kbd> | Show / hide this list |
| <kbd>F1</kbd> | Open / close this manual |

<kbd>⌘/Ctrl</kbd>+<kbd>R</kbd> does nothing in the installed app, on purpose: it used to
reload BORN and wipe what was on screen.

<kbd>/</kbd> only jumps to the search box when you're not already typing somewhere
else (it won't interrupt you mid-sentence in the Message dialog, for example).
