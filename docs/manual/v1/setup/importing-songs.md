# Importing songs

BORN ships with a large built-in song library, but a church's own songbook or a
visiting worship leader's set list can be brought in too.

On the **Songs** tab, click **Import…** (top-right). Two options:

- **From a file…** — pick one or more files, or a whole folder. BORN accepts
  ProPresenter files (`.pro`, `.pro7`), ChordPro (`.cho`, `.crd`, `.chordpro`,
  `.chopro`), plain text (`.txt`), Word documents (`.docx`), PDFs (`.pdf`), and XML
  song exports (`.xml`).
- **Paste text…** — paste lyrics directly, for a song that only exists on a sheet
  of paper or a text message.

After an import, BORN reports how many songs were **added**, how many were
**already present** (skipped, not duplicated), how many **failed**, and how many
**need a quick review** — a review step appears automatically for any song whose
title, key, or slide breaks weren't fully clear from the source file, so you can
confirm or fix them before they're added to the library.

A song imported this way is marked **Imported** in search results, so it's easy to
tell apart from the built-in library.
