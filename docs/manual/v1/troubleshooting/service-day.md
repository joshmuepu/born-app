# On service day

## Saving and reopening a queue

Click **Save** (top of the Service queue panel) to save the current queue to a
file — useful for a repeating order of service, or to hand off to whoever's
running the next service. **Save** is only enabled once the queue has at least one
item in it.

Click **Open** to replace the current queue with one from a saved file, or
**Import** to add a saved file's items onto the end of the current queue instead
of replacing it (useful for combining a standing hymn list with this week's
sermon). From the empty-queue start screen, **Open a saved service…** does the
same as **Open**, and any recently-used files are listed right there to reopen
with one click.

## The screen shows nothing

Check, in order:

1. Is **Hide screen** turned on? It turns amber and reads **Show screen** when
   active — click it to bring the picture back.
2. Does the header say **Close projection**? If it still says **Open projection**,
   the projection window was never opened — click it.
3. Is the Congregation screen set correctly? See
   [Connecting a second screen](../setup/displays.md).
