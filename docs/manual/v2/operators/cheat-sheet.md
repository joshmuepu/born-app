# Service Day cheat sheet

*One page. Print it (Help → this page → **Save this page as PDF**) and keep it at the
sound desk.*

## Before people arrive

1. Turn on the Congregation screen (and Stage monitor, if used) **first**.
2. Open BORN.
3. If nothing was projecting last time: click **Open projection** (top of the
   window). The Congregation screen should go to a plain black screen — that's
   correct, it means it's ready and showing nothing yet.

![The Back / Next bar at the bottom of the Service Queue, with the "on screen" line above it showing exactly what's currently projected.](../images/cheat-queue-bar-small.png)

## During the service

| To do this | Do this |
|---|---|
| Find a sermon quote | Type a word/phrase in the search box → click a result's **Project** |
| Find a Bible verse | Click **Bible** → type a reference like `John 3:16` → **Project** |
| Find a song | Click **Songs** → search → **Project** |
| Move to the next slide | Press **→** or **Space**, or click **Next** |
| Go back a slide | Press **←**, or click **Back** |
| Black out the screen | Press **Esc**, or click **Hide screen** — it relabels to **Show screen** while hidden |
| Bring it back | Press **Esc** again, or click **Show screen** |
| Show a one-off announcement | Click **Message** → type it → **Show message** (clears itself after ~10s) |

The line above the Back/Next bar always shows exactly what's on the screen right now
— if it says "Screen is hidden" or "Projection window is closed," that's why nothing
is showing.

![The Hide screen / Show screen button.](../images/cheat-hide-show-small.png)

## If something looks wrong

| Symptom | Try this |
|---|---|
| Nothing shows on the Congregation screen at all | Is the TV/projector on its **right input**? Does the top button still say **Open projection** — meaning it hasn't been clicked yet this session? |
| It's on the wrong screen | Open the **Screens** menu (top right) → check which display Congregation is set to |
| A warning dot/line appears near a channel or display | Open **Screens → Manage…** — the exact message tells you what to do (see [Troubleshooting](../troubleshooting/service-day.md)) |

Full manual: press **F1** inside BORN, any time.
