# DRAFT — possible v1.13.3 notes (not added to CHANGELOG.md)
- Pressing Esc (or the phone's Hide screen) while a sermon is on the screen no longer scrolls the sermon list. It stays where you were.
- The same for the Bible chapter (it used to close and jump back) and for song slides (they shifted a few pixels).
- Esc no longer moves the cursor to the song key button when the key picker is closed.
- Opening a queued sermon range now shows its first paragraph, and pressing Project keeps the paragraph that went to the screen in view.
- Sermons and book chapters with no paragraph numbers: each slide is now labelled "Slide 1, 2, 3 …" and only the slide on the screen is lit (before, all of them were lit with an internal code).
- Very long paragraphs (more than 26 pages) now have sensible page labels.
