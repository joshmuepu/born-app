# 04 · Idea backlog (features, not UI fixes — not part of the approval proposals)

1. **Status centre.** One popover (from the Now dock) listing screens, stage, Graphics/OBS, phones, audio output and the last problems, each with a one-tap fix ("Restart the sound", "Choose the output…", "Reconnect"). Today these are in four places.
2. **Service templates and a "tonight" plan.** Save a queue as a template ("Sunday morning") and start next week's service from it with dates filled in.
3. **Kiosk / lock mode.** Lock the operator window to Run view with a PIN so a second volunteer cannot change settings; the phone keeps working.
4. **Hand-off between two operators.** "I'm taking over" with a transfer of the live queue position, so two people with two laptops never fight over the screens.
5. **A printable operator quick card** (one page: the glossary, Esc / Shift+Esc, Space, ⌘K, who to call), generated from the shortcut table.
6. **Global search scope chips** in ⌘K (Sermons · Bible · Songs · Media · Actions) and a "recent" section; today the palette mixes everything.
7. **Plain-words pass on Screens ▸ Manage** (Channel / Destination / Profile): replace with "Screen", "What it shows", "Look", with the technical names behind an Advanced switch.
8. **Interface localisation.** All interface text is English strings in components; extract to a catalogue, test string expansion (German +35 %) and RTL layout (Arabic, Hebrew). Sermon text languages are already handled.
9. **Rehearsal mode.** Run the queue with a "rehearsal" watermark on the preview and no output, to practise.
10. **Scheduled service timeline** with durations, so the person at the desk sees "song 4 min, sermon 55 min" and the time left.
11. **Per-item notes for the operator** (not shown on the screens): "wait for the pastor's signal".
12. **Alert/Message presets** ("Please silence your phones", "Nursery: parent of …") one tap from the Message dialog.
13. **Output health checks before service** (a real test pattern on each screen, an audio blip on the tape output) folded into "Is tonight ready?".
14. **Update and About pages** showing what changed in plain language, with a rollback link.
15. **A "last session crashed" recovery card** on start that shows the queue that was restored and what was live.
